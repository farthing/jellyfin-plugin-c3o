Checks the library and downloads an SRT for every video that has none in the languages below. It searches with the subtitle providers already installed on this server.

Languages

Up to five, most important first. Leave a slot on "None" to skip it. With no language set, nothing is downloaded.
Newest additions to the library are always handled first.

What to check

What counts as already having subtitles

On: a video whose file already contains, say, English text subtitles gets no English SRT. Off: only an SRT file next to the video counts, so one is downloaded even if the file has that language built in.

Which subtitles to accept

Guarantees the timing fits, but far fewer titles get a subtitle. Off: the most-downloaded subtitle for the title is used when there is no exact match.

Limits

A run always stops by itself when the provider's daily download limit is used up, and the next run continues from there.
